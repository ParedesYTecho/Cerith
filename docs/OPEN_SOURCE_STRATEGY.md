# Open Source Strategy

Status: Draft
Project name: Cerith (working name)

## Goal

Be genuinely open source while maintaining a distinct official product.

## Constraint

Real open source permits forks, modification and redistribution.

Therefore:

> “source visible but nobody may copy it”

is not the project model.

## Licence (D-035)

The whole repository, documentation included, is GPL-3.0-or-later with the Microsoft-components permission in `LICENSE-EXCEPTION.md`. The name, logo and artwork are excluded. A separate permissive licence for a future plugin SDK is still to be decided when the SDK exists.

## Product moat

Official Cerith should remain valuable through:

- design;
- signed releases;
- reliable providers;
- official registry;
- curated widgets/themes;
- QA;
- update channel;
- documentation;
- community;
- brand.

## No custom fake-open-source license

Do not create a “no competitors” or “non-commercial open-source” license.

If the project ever chooses source-available instead, name that decision honestly.

## Still open before a binary release

- full third-party notice bundle;
- brand policy and name/trademark review;
- contribution policy;
- check that no private artifact is in the history.
