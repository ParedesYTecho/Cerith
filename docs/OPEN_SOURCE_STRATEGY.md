# Open Source Strategy

Status: Draft
Project name: Cerith (working name)

## Goal

Be genuinely open source while maintaining a distinct official product.

## Constraint

Real open source permits forks, modification and redistribution.

Therefore:

> “source visible but nobody may copy it”

is not the project model.

## Provisional licensing direction

```text
main application/core
→ GPL-3.0-or-later candidate

plugin SDK / protocol contracts / examples
→ Apache-2.0 or MIT candidate

documentation
→ separate documentation license

official name/logo/artwork/store assets
→ separate brand/copyright policy
```

No final license is committed until dependency review.

## Product moat

Official Cerith should remain valuable through:

- design;
- signed releases;
- reliable providers;
- official registry;
- curated widgets/themes;
- QA;
- update channel;
- documentation;
- community;
- brand.

## No custom fake-open-source license

Do not create a “no competitors” or “non-commercial open-source” license.

If the project ever chooses source-available instead, name that decision honestly.

## Before public release

- dependency/license inventory;
- final code license;
- SDK license;
- brand policy;
- contribution policy;
- third-party notices;
- clean history;
- no private artifacts;
- name/trademark review.
